# ESP32-C3 SuperMini — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans for native execution after Edwar reviews this plan. Steps use checkbox syntax for tracking.

**Goal:** Entregar un .ino compilado que genere telemetría sintética compatible para probar la placa real en local y Vercel.
**Architecture:** Firmware sin sensores/Wi-Fi ni credenciales. Emite NDJSON USB; estación y relay ya verificados por las dos entregas anteriores.
**Tech Stack:** Arduino CLI 1.2.2 existente, Arduino-ESP32 3.3.11 instalado,
FQBN `esp32:esp32:esp32c3:CDCOnBoot=cdc`; confirmar opción mediante board details
antes de compilar, sin actualizar toolchains globales automáticamente.
**Spec:** [Recepción primero](../specs/2026-10-29-cubeos-telemetry-first-design.md).

## Global Constraints

- No flashear/seleccionar dispositivos automáticamente. Edwar hace la carga.
- Un envelope v1 con payload v2 por LF, CS01, baud nominal 115200; sin logs mezclados.
- Secuencia creciente, uptime millis; H/E/O/I sintéticos. Sin inventar actitud/SOC/UV.
- No bloquear indefinidamente esperando Serial. Sin claves/cuentas/canales en firmware.
- Compilación y PTY no acreditan placa/cable físicos. No declarar todo terminado
  hasta recibir evidencia física verificable.

## Review Focus

1. Reinicio real: dos H BOOT bajos distintos permiten al backend reconocer nueva época.
2. Wrap millis/secuencia: uint32 y diferencias temporales seguras.
3. USB CDC no abierto: el loop no queda bloqueado esperando monitor.
4. Salida/tramas dañadas o excesivas: parser conserva evidencia y no inventa datos.
5. Silencio/reconexión: valores envejecen, no se reemplazan por DEMO ni cero.
